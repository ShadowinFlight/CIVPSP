# CIVITAS PSP

**V0.3.1 开发版** · PSP 1000 回合制 4X 策略游戏

[**简体中文**](README.md) | [English](README.en.md)

## 功能

* **完整 4X 流程**：探索 64×48 地图、建城、扩张边界、研究 30 项科技、组建军队，通过征服、科技、外交或分数获胜。
* **四个文明与蛮族**：玩家奥蕾莉亚，以及博瑞亚、赛琳、德雷文和敌对蛮族。单位与城市使用文明色贴图变体和底部归属色条。
* **城市管理**：5×5 工作范围、市民分配/锁定、食物成长与饥荒、生产队列、金币加速、9 种建筑、边界扩张和地块购买。
* **城市攻防**：城市拥有 100 HP 和 100 城防；守军必须先被消灭。攻击先耗尽城防，再扣 HP；城防只能由城市格上或相邻的工人修复，城墙把上限提升到 150 并降低单次修复量。城市总览只显示 HP 和城防池。
* **军事系统**：定居者、战士、侦察兵、剑士、骑手、工人、医疗兵；地形/城市防御、反击、治疗和城市占领。
* **医疗兵**：非战斗支援单位，费用 12，4 移动 / 2 视野 / 0 力量；相邻（含斜向）友军休息回血时额外 +10 HP，多个医疗兵不叠加，不能攻击。
* **森林砍伐**：工人站在己方森林上且最近城市有生产队列时，可一次性砍伐：该格变草原（保留资源与已有改良），消耗全部移动力，并给该城市 +20 生产。
* **外交**：关系、赠礼、贸易、互不侵犯、开放边境、同盟、谴责、AI 提案和外交胜利。
* **回合简报**：AI/回合结束阶段的战斗、攻城、宣战、议和和 AI 提案会集中显示在居中的新回合简报中，每页 3 条，可翻页查看。
* **两种模式**：经典模式可选 100/200/300 回合，到达上限后按分数结算；无尽模式没有回合上限，直到征服、科技或外交胜利/失败。
* **三种难度**：简单、普通、困难。难度影响开局单位、AI 金币、宣战时机和蛮族压力。
* **中英文界面**：默认中文，可在选项切换 English；主菜单和暂停菜单均可进入 12 页游戏手册。
* **科技页**：按四个时代分组显示，包含每个时代的完成进度、科技花费、前置科技和解锁内容；`L/R` 在时代之间跳转。
* **探索小地图**：右下角面板，默认收起，按 `L` 打开/关闭；显示已探索地形、当前可见区域、城市、单位、光标和镜头框。
* **侦察兵自动探索**：在侦察兵行动菜单中选择自动探索后，每回合自动走向最近的未探索地块，直到移动力耗尽；可随时关闭。
* **平滑地形过渡**：已探索地块与上下左右已探索邻格之间用 alpha 渐变混合地形颜色，柔化生硬边界，同时不泄露迷雾中的地形；地块深色描边已移除，避免网格感。
* **音频**：Python 生成的 8 个时代/和平战争背景循环，每个循环包含 8 个一拍长度的自然音阶和弦与七和弦色彩，按玩家时代与战争状态自动切换并交叉淡入；另有 8 个音效，可在选项中开关音乐。
* **PSP 表现**：自定义 XMB 图标/背景、菜单淡入/滑入/选中辉光、金色压印菜单标题，以及文明颜色单位。

## V0.3.1 更新

V0.3.1 在 V0.3 基础上重写背景音乐和声，加入非战斗医疗兵和工人森林砍伐，并移除地形图块的深色描边；保留 V0.3 的时代音乐、平滑过渡、自动探索、金色标题及全部既有系统。

### 和声与配乐

* 四个时代仍各有和平/战争两首 8 秒循环，但每个循环改为 8 个自然音阶和弦，每个和弦约 1 秒，并加入 maj7 / m7 / 属七和弦色彩。
* 远古 Am–F–C–G–Am–Dm–Fmaj7–Em；古典 Cmaj7–Am–Fmaj7–G7–C–F–Dm7–G7；中世纪 Gm–F–E♭–F–Gm–Cm–E♭–Dm7；文艺复兴 D–A7–Bm7–F♯m–Gmaj7–D–Em7–A7。
* 战争变体继续降 2 个半音并加入更暗的持续音与打击；循环首尾交叉淡化和约 0.4 秒切歌交叉淡入保持不变。

### 医疗兵

* 新增 `MEDIC` 生产项，费用 12，无科技前置；基础 4 移动 / 2 视野 / 0 力量，不能攻击或建城。
* 相邻（含斜向）的友军在本回合未移动/攻击、满足休息回血条件时，额外恢复 10 HP；多个医疗兵不叠加。
* 医疗兵可以移动和探路，但无法执行攻击、建城或工人改良。

### 森林砍伐

* 工人在己方城市拥有的森林地块上，可从行动菜单选择 `CHOP FOREST`。
* 砍伐消耗本回合剩余移动力，森林变为草原，保留该格资源与已有改良，并给最近的有生产队列的己方城市 +20 生产。
* 没有生产队列时不会消耗森林或移动力，行动菜单会提示先设置队列；非己方森林、城市中心和没有森林的地块不会显示砍伐选项。

### 地形接缝

* 地形图块不再绘制深色矩形描边；保留四方向 alpha 过渡，因此相邻地形仍有柔和边界，但不会形成明显网格线。
* 贴图集扩为 256×256，以容纳第 6 个单位/城市图标列；城市图标索引不变。

### 兼容与验证

* 存档格式仍为 **version 3**；`UNIT\_MEDIC`、`PROD\_MEDIC` 等枚举追加在末尾，V0.3 及更早存档可直接读取。
* 14 个 host 套件、i18n 和音频检查通过；`test\_units` 覆盖医疗兵属性、攻击拒绝、相邻回血和不叠加，`test\_improvements` 覆盖砍伐成功、拒绝条件和生产入账，`test\_combat` 覆盖医疗兵平民攻击错误。
* PPSSPP 启动日志显示 `CIVITAS PSP V0.3.1`；WSLg 截图仍为黑屏，真机视觉/听感验收待完成。
* `v0.3` 标签及 `release/v0.3/` 保持冻结；V0.3.1 使用新标签和 `release/v0.3.1/`。

## V0.3 更新（历史）

V0.3 加入时代/和平战争背景音乐、平滑地形过渡、侦察兵自动探索和金色压印菜单标题；保留 V0.2.2 的迷雾修复与全部既有系统。

### 时代与战争音乐

* 新增 8 个约 8 秒的背景循环：远古、古典、中世纪、文艺复兴各有一首和平曲和一首战争曲。
* 菜单、手册、选项和新游戏界面固定使用远古/和平；进入地图后按玩家最高时代和是否与存活的主要对手交战自动选曲。
* 战争变体降低 2 个半音，并使用更暗的和声与打击；切歌使用约 0.4 秒交叉淡入，播放循环已做首尾交叉淡化。
* 音乐仍可在选项菜单中关闭；8 个音效保持不变。

### 平滑地形

* 地图渲染新增过渡图集：每个地块根据左侧、右侧、上方、下方四个方向，与已探索邻格混合地形颜色。
* 过渡只朝向已探索邻格生成；未探索区域仍由迷雾遮住，不通过渐变泄露地形。
* 过渡图集使用线性过滤；基础地形保持像素风，细节层、单位、城市和迷雾继续使用原有绘制顺序。

### 侦察兵自动探索

* 侦察兵行动菜单新增 `AUTO-EXPLORE` 开关；开启后立即用剩余移动力探索，之后每回合结束重置移动力时继续自动探索。
* 自动探索用 BFS 寻找最近的可达未探索地块，避开不可通行地形、城市和所有单位；没有可达目标时保持原位。
* HUD 会为单位名称追加 `AUTO` 标记；自动探索状态保存在 `Unit.acted` 的 `0x80` 位，不新增存档字段。

### 菜单标题

* 主菜单、手册、选项、新游戏、暂停、保存和读取界面的标题改为多层金色文字：深色投影、暗金斜面、亮金主体和左上高光。
* 标题使用线性字体过滤和加宽的中日韩字库格，避免放大后出现锯齿或相邻字形串色。

### 兼容与验证

* 存档格式仍为 **version 3**，与 V0.2.2 / V0.2.1 / V0.2 存档兼容；自动探索位对旧版本读取器无影响。
* 14 个 host 测试套件继续通过；`test\_units` 新增自动探索、回合重置保留和时代/战争状态覆盖；i18n 与生成音频检查通过。
* `v0.2`、`v0.2.1`、`v0.2.2` 标签及对应发布包保持不变，V0.3 使用新的标签和发布包。

## V0.2.2 更新（历史）

V0.2.2 修复战争迷雾中的信息泄露，并保留 V0.2.1 的回合简报和城市总览清理。

### 战争迷雾修复

* 光标移到当前不可见的敌方单位格时，底部状态栏和地块信息面板都不再显示单位类型、归属、HP 或移动力；玩家自己的单位仍会显示。
* 未探索地块不再通过底部状态栏或信息面板泄露城市信息；已经探索过的城市仍保留已知信息。

### 回合简报（V0.2.1）

* AI/回合结束阶段的单位战斗、城市强攻、宣战、议和和 AI 提案会进入临时队列，在新回合开始时以居中简报显示。
* 每页显示 3 条事件；`L/R` 翻页，`×/○` 关闭。
* 玩家主动攻击仍使用底部提示，避免打断操作。
* 每条战斗记录包含格坐标、双方文明和单位、伤害/反击伤害、单位死亡结果、城防/城市 HP 伤害和占领结果。
* 涉及玩家的战斗始终记录；AI 对 AI 的战斗只在玩家可见格记录，不泄露战争迷雾。
* 队列最多 32 条，不写入存档；新游戏、读档、关闭简报和 `World\_EndTurn` 开始都会清空。

### 城市攻防与模式（V0.2 基础）

* 城市不再是“走进空城即占领”：必须先击败驻守单位，再对城市发动多次攻击。
* 城墙同时提供城防池上限 150 和更慢的工人修复速度（+15，而不是 +25）。
* 城市未在本回合被攻击时，回合结束恢复 10 HP；城防不会自动恢复。
* 城市总览只显示 `HP` 和 `城防` 池，旧的 `防御` 数值行已移除；内部防御强度仍参与伤害计算。
* 新游戏可选简单/普通/困难；经典模式可选 100/200/300 回合；限时模式已移除。
* 外交新增“谴责”：消耗 8 点关系，每个对手每回合最多一次。
* `L` 单独切换小地图；`R` 选择下一个仍有移动力的玩家单位；摇杆平移镜头时选中格跟随视野中心。
* 科技页加入时代标题、时代进度、前置科技和花费详情。

### 存档与兼容（V0.2 基础）

* 存档格式升级为 v3；v2 存档会迁移：旧“标准”存档变为经典 200 回合，旧“限时”存档变为无尽模式，城市战斗字段初始化为满值。
* 回合简报队列不写入存档，不改变存档格式。
* `v0.2` 标签仍指向 `c733769`，`v0.2.1` 保持原发布状态；V0.2.2 是新的补丁发布包，位于 `release/v0.2.2/`。

## 操作

|输入|功能|
|-|-|
|方向键|移动地图光标|
|摇杆|平移镜头，并让选中格跟随视野中心|
|×|选择 / 确认 / 行动|
|○|返回 / 暂停|
|△|单位行动菜单|
|□|地块信息|
|L|打开/关闭小地图|
|R|选择下一个仍有移动力的玩家单位|
|START|外交|
|SELECT|结束回合|

城市界面：`L/R` 切换标签，`×` 选择生产/市民操作，`△` 购买/锁定，`□` 自动分配市民。科技页中 `L/R` 跳转到上一个/下一个时代。工人站在己方城市格上或相邻格时，`△` 菜单会出现“修复城防”；站在己方森林且城市有生产队列时会出现“砍伐森林”。侦察兵的 `△` 菜单会出现自动探索开关，可在任意回合开启或关闭。医疗兵不能攻击，但可站在友军旁加速休息回血。

## 构建与运行

### 依赖

* [pspdev](https://github.com/pspdev/pspdev) 工具链（加入 `PATH`）
* GNU Make
* Python 3 + Pillow（重新生成资源时需要）
* Noto Sans CJK / DejaVu 字体（重新生成中文字库和 XMB 美术时需要）

### 构建

```bash
export PATH=$PATH:/home/zhang/pspdev/bin
make clean
make -j4
```

构建后在项目根目录生成 `EBOOT.PBP` 和 `civpsp.elf`。

重新生成字符串、字体、音频、XMB 美术和地形图集：

```bash
make assets
```

### 测试

```bash
make test
```

当前 V0.3.1 测试门槛为 **14 个 host 测试套件**，外加中英文/字库检查和生成音频检查。`test\_units` 新增医疗兵属性、攻击拒绝、相邻回血、叠加限制和友方领土回血，并继续覆盖侦察兵自动探索、行动位在回合重置后保留、回合结束自动探索、时代判定和战争状态判定；`test\_improvements` 新增森林砍伐成功、无队列/非己方/城市中心/非森林拒绝和生产入账；`test\_combat` 覆盖医疗兵不能攻击；`test\_save` 验证自动探索高位能随存档往返。既有套件继续覆盖城市强攻、守军屏蔽、城墙/修复/回血、谴责、难度开局、存档 v3 往返和 v2 迁移。`check\_audio.py` 验证 8 个音乐循环与 8 个音效，合并生成的 16 个 WAV 全部通过格式和峰值检查。

### PPSSPP 运行

```bash
PPSSPP --windowed --graphics=software civpsp.elf
```

也可以直接在 PPSSPP 中打开 `EBOOT.PBP`。PSP 安装路径：

```text
ms0:/PSP/GAME/CIVPSP/EBOOT.PBP
```

`ICON0.PNG` 和 `PIC1.PNG` 会由构建过程打包进 EBOOT。

* 14 个 host 测试套件：地图、单位、城市、科技、改良、战斗、回合简报队列、AI、外交、摇杆、存档、M7 计分、M8 科技/胜利、M9 i18n
* `tools/check\_i18n.py`：翻译覆盖、格式化占位符、字形覆盖、行宽
* `tools/check\_audio.py`：8 个音乐循环和 8 个音效的 WAV 格式、非静音峰值和旧 `ambient.wav` 清理检查

PPSSPP 已检查主菜单、手册、地图、城市标签、外交、存档、小地图、分数结算以及中英文切换。V0.2 最终 EBOOT 另外做了功能冒烟：困难/经典 300 开局、`L`/`R`、建城、城市与科技页、谴责、有无守军的城市强攻，以及 v2 标准存档迁移。V0.2.1 构建验证了 AI 战斗后的回合简报：日志显示 `ai combat ... dmg=30 counter=30`、`report: open turn=2 events=1`，按 `×` 后出现 `report: dismissed turn=2`。V0.2.2 验证了 `CIVITAS PSP V0.2.2` 启动日志与迷雾修复路径。V0.3 的 PPSSPP 启动日志显示 `CIVITAS PSP V0.3` 和 `audio: channel=7 44100Hz stereo, 8 era/mood music tracks`。V0.3.1 的 PPSSPP 启动日志显示 `CIVITAS PSP V0.3.1`；医疗兵、砍伐、八和弦和地形描边移除由 host 测试、生成资源和图集检查覆盖。WSLg 下 X11 截图仍为黑屏，因此本轮无法在本地确认金色标题、地形接缝和新配乐的最终观感/听感，需在 PSP 1000 或可截图的 PPSSPP 环境中验收。

## 已知限制

* V0.3.1 是开发快照，PSP 1000 最新包仍在最终验收中；主要验证目标为 PPSSPP。
* AI 暂不生产或使用医疗兵；医疗兵和森林砍伐目前只面向玩家。
* 没有海军单位；海岸和海洋不可通行。
* 贸易仅为金币交易；开放边境共享视野，但暂不限制单位穿越。
* 边界只通过影响力或购买扩张，暂无文化/边境移动门槛。
* 暂无资源交易、重叠音效和设置菜单内的小地图开关。
* 同时只播放一个音效（另有背景音乐）。
* 背景音乐为约 8 秒的生成循环，每循环 8 个一拍和弦；切换时代或战争状态时使用交叉淡入，不是完整作曲。
* 存档格式为 version 3；v2 及更早的 M7/M8/M9 开发版存档会按迁移规则加载。

## 版本

**V0.3.1** 是 V0.3 之后的功能更新，加入八和弦时代配乐、非战斗医疗兵、森林砍伐，并移除地形图块描边；V0.3 的时代音乐、平滑地形、侦察兵自动探索、金色标题，以及 V0.2.2 的迷雾修复、V0.2.1 的回合简报、城市总览清理和 V0.2 的城市攻防、难度、经典/无尽模式、谴责、时代分组科技页与存档 v3 全部保留。`v0.2`、`v0.2.1`、`v0.2.2`、`v0.3` 标签及对应发布包保持冻结，V0.3.1 使用新的标签和发布包。V0.1 仍是首个 GitHub 开发版，历史里程碑标签保留在仓库中。
