# CIVITAS 游戏数据表

数据版本：**V0.1**
来源：当前 `src/data.c`、`src/unit.c`、`src/city.c`、`src/tech.c`、`src/combat.c`、`src/world.c`、`src/diplomacy.c`。

说明：

* **F/P/G/S** 分别表示食物、生产、金币、科研。
* 单位移动力使用“半步”单位：直走 2 点，斜走 3 点；界面显示的是总移动力。
* 所有单位最大 HP 为 **100**，同格不能堆叠单位。
* 所有数值都是当前版本的基准值；科技效果可能在城市产出上追加。

## 6\. 城市经济与成长

### 城市产出

城市每回合产出：

```text
食物 = 城市中心 2 + 已工作地块食物 + 建筑食物 + 科技效果
生产 = 城市中心 2 + 已工作地块生产 + 建筑生产 + 科技效果
金币 = 城市中心 1 + 已工作地块金币 + 建筑金币 + 科技效果
科研 = 城市中心 1 + 建筑科研 + 科技效果
影响力 = 1 + 建筑影响力
防御 = 1 + 建筑防御 + 城墙科技效果
```

自动分配市民时的地块评分：

```text
评分 = 食物×5 + 生产×3 + 金币×2
若地块有资源，再 +2
```

### 成长与饥荒

```text
食物盈余 = 城市食物 - 人口×3
成长阈值 = 10 + 5×人口
```

* 食物储存达到成长阈值时人口 +1，并扣除相应阈值。
* 人口上限为 20。
* 食物储存为负时，人口下降，最低为 1。
* 食物/生产储存上限均为 30000。

### 生产、购买与加速

|项目|公式/规则|
|-|-|
|生产进度|每回合增加城市生产；队列为空时生产储存清零|
|破产|回合开始时金币为负，城市生产减半、科研减半|
|加速费用|`max(5, 剩余生产 × 2)` 金币|
|加速结果|立即完成当前生产项目|
|队列|最多 5 项；建筑不可重复排队|
|单位放置失败|没有空格时生产会保留，等待下一回合|

### 边界、影响力和地块购买

|项目|公式/规则|
|-|-|
|每回合影响力|1 + 建筑影响力（纪念碑 +1）|
|边界成长阈值|`10 + 5 × max(已拥有地块 - 9, 0)`|
|边界成长|影响力达到阈值后，自动取得相邻且评分最高的未拥有地块，并扣除阈值|
|地块购买费用|`15 + 5 × max(已拥有地块 - 9, 0)` 金币|
|可购买地块|必须与现有领土 8 向相邻，不能是城市中心，不能已拥有|
|购买效果|立即取得地块，标记为已探索/可见，并在有空闲市民时自动分配|

### 每回合金币与科研

```text
玩家金币收入 = 所有城市金币之和
              - 所有建筑维护费
              - ceil(玩家单位数 / 3)

玩家科研收入 = 所有城市科研之和
              - 如果回合开始时金币为负：每城科研先减半
              - 再乘以（100% + 科研加成%）
```

* 单位维护：每 3 个玩家单位 1 金币/回合，向上取整。
* AI 城市收入 = `max(0, 城市金币 - 建筑维护费)`；AI 不支付单位维护。
* 贸易协议额外提供 **+2 金币/回合，持续 10 回合**（玩家作为接收方时）。
* 玩家金币可以为负；回合开始时金币为负，生产减半、科研减半。

### 科研

|项目|规则|
|-|-|
|科研来源|城市科研产出；地形本身不产科研|
|研究选择|必须满足前置科技|
|切换研究|切换到不同科技会清空当前研究进度|
|重复选择|选择当前正在研究的科技会保留进度|
|完成|科研进度达到科技成本即完成；完成后停止研究，等待选择下一项|
|科研加成|印刷术 +10%，科学方法 +10%，合计最高 +20%|
|AI 科研|不追踪科研点；按回合推导，每 8 回合获得 1 项符合前置的科技|

## 8\. 战斗数据

|项目|公式/规则|
|-|-|
|单位最大 HP|100|
|基础伤害|`30 + (攻击方力量 - 防御方力量) × 5`|
|伤害范围|限制在 5–95|
|防守地形加成|森林或丘陵：防御方力量 +1|
|城市防守加成|城市基础防御 1 + 建筑防御 + 封建制城墙效果|
|反击|防守方存活时，按防守方基础力量对攻击方造成一次伤害|
|攻击消耗|攻击后攻击方剩余移动力归零|
|单位死亡|HP 降到 0 时移除|
|城市占领|城市中心没有单位时，相邻军事单位可占领城市|
|战斗后移动|防守方死亡时，攻击方可进入目标格或占领城市|

`Combat\_DefenseStrength` 会把城市防御、森林/丘陵加成计入防御方力量。  
反击使用的是防守方的**基础力量**，不重复计算地形/城市防御加成。

## 10\. 胜利条件与计分

### 胜利条件

|胜利|条件|
|-|-|
|征服胜利|占领所有对手首都|
|科技胜利|完成天文学、科学方法、导航术三个后期项目|
|外交胜利|与所有存活对手同盟并维持 10 回合|
|分数胜利|200 回合或限时结束，玩家分数不低于最佳对手|
|失败|已建城后失去所有城市；或分数低于最佳对手|

### 分数公式

每座城市：

```text
+10
+ 人口 × 6
+ 已拥有地块数
+ 建筑数 × 5
```

每个单位：

```text
+4
+ floor(当前 HP / 25)
```

其他：

```text
+ 已研究科技数 × 10（蛮族除外）
+ floor(正金币 / 20)
```

标准模式在回合数超过 200 时结算；限时模式在倒计时结束时结算。分数相同时玩家获胜。
